## Recent GitHub updates

- **Pull request Overview page (public preview):** A new opt-in Overview page puts a compact merge-readiness summary at the top of a pull request, with filters for unresolved conversations and newest-first comment sorting. Try it with the "Try the Overview page" button in the PR header. Source: [GitHub Changelog, Nov 5, 2026](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview)
- **`pull_request_target` blocked by default on December 2:** GitHub Actions will block this trigger by default in public repositories unless an Actions event policy allows it. Brownouts run on November 9 and November 16 (16:00–18:00 UTC). Check Insights to see which workflows would be affected. Source: [GitHub Changelog, Nov 2, 2026](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
- **Secret scanning for Actions workflow logs (public preview):** Logs are now scanned after a workflow run completes, with findings listed in the repository's secret scanning alerts. Available to Enterprise Cloud with Secret Protection or Advanced Security, and off by default. Source: [GitHub Changelog, Nov 9, 2026](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs)
- **Accessibility statements on GitHub:** `ACCESSIBILITY.md` files are now highlighted, helping maintainers document accessibility goals, known barriers, and reporting processes. Source: [GitHub Blog, Nov 5, 2026](https://github.blog/latest/)
- **Agentic engineering with Copilot:** A guide to using GitHub Copilot to plan, write, review, and investigate production issues, and where human judgment still matters. Source: [GitHub Blog, Nov 6, 2026](https://github.blog/latest/)
